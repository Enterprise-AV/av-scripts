SignageSetup - Admin Guide

What It Does

SignageSetup automates the commissioning of Azulle Access4 signage players running Zoom Rooms digital signage on Windows IoT. The setup has two phases:

Phase 1 — Initial Setup (Setup.bat)

  1. Connects to PublicGuest Wi-Fi (captive portal network)
  2. Disables Ethernet and Network Discovery
  3. Installs the Intel Wi-Fi driver if needed
  4. Posts device info (serial number, MAC addresses) to Smartsheet
  5. Enrolls the device in Zoom Device Management (ZDM)
  6. Installs or updates Zoom Rooms to the minimum required version
  7. Creates scheduled tasks for network promotion, connectivity monitoring, and cache cleanup

Phase 2 — Network Promotion (Automatic)

After the device's MAC addresses are whitelisted via ServiceNow:

  1. The NetworkPromotion scheduled task detects the whitelist approval
  2. Deletes the PublicGuest profile and connects to IoT-Device (802.1X)
  3. Tests connectivity to zoom.us
  4. Re-enables Ethernet and disables Network Discovery
  5. Removes itself (the promotion tasks) once complete

How It's Distributed

Unlike the other scripts, SignageSetup is not per-project. There is one shared release used across all projects:

  • Download: SignageSetup-Deploy/releases/latest

The technician downloads the zip, extracts it to a USB drive, plugs it into the signage player, and runs Setup.bat. The script copies itself to the desktop and relaunches from there.

Self-updating: After initial setup, a scheduled task (PingAndRestart) checks for updates every 15 minutes. All deployed PCs stay in sync automatically.

Secrets

SignageSetup secrets are on the SignageSetup source repo, not on vendor-scripts. They are shared across all projects.

Secret Purpose Where
SIGNAGE_SMARTSHEET_API_TOKEN Smartsheet API token for posting device info SignageSetup source repo
SIGNAGE_GITHUB_PAT Fine-grained PAT for self-update and error reporting SignageSetup source repo
MANAGEMENT_PAT Classic PAT to push releases to SignageSetup-Deploy SignageSetup source repo

Smartsheet Integration

The commissioning sheet tracks all deployed signage players with:

  • Serial number, Wi-Fi MAC, Ethernet MAC
  • Current script version (updated automatically on each update check)
  • Update errors (if the self-update fails, the error is posted to the sheet)

Scheduled Tasks

Task Schedule Purpose Lifecycle
PingAndRestart Every 15 min Connectivity monitor, Zoom Rooms watchdog, self-update check Permanent
NetworkPromotion Hourly + on boot Transitions from PublicGuest to IoT-Device after MAC whitelist Self-deleting
ZoomCacheCleaner Weekly (Mon 3 AM) Cleans stale Zoom Rooms cache and logs Permanent

Rotating the Smartsheet API Key

  1. Update SIGNAGE_SMARTSHEET_API_TOKEN on the SignageSetup source repo
  2. Push any change (or use workflow_dispatch) to trigger a new release
  3. Within 15 minutes, all deployed PCs will download the update with the new key

Troubleshooting

Issue Cause Fix

Signage content freezes Stale DigitalSignage cache Run ZoomCleanup.bat or wait for the weekly cache cleanup
