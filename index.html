Why do I need to request a new project?

Each project gets its own set of API keys (Smartsheet, Xyte, Neat Pulse) and its own GitHub repository. These keys give the tool write access to our inventory systems, so they need to be issued, tracked, and revoked by the AV engineering team. The build pipeline injects the keys into the exe at build time so vendors never see or handle them directly.

To request a new project, contact the AV engineering team with the project ID (e.g. B143), project name, and vendor name.

Distributing to Vendors

  1. Find your project in the table below
  2. Right-click the download link for the script you need and copy the URL
  3. Send the link to your vendor (or use it yourself)

The vendor downloads the zip once. After that, the exe updates itself automatically every time it runs -- no need to send new links when we push fixes.
