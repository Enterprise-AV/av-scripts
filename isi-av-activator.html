ISI-AV-Activation

What It Does

ISI-AV-Activation.exe retrieves Neat Pulse enrollment codes and Zoom Rooms activation codes for a specific building. When a vendor or engineer runs it, the tool:

  1. Loads all Neat Pulse rooms for the configured building
  2. Fetches or generates enrollment codes for each room
  3. Authenticates with Zoom and loads Zoom Rooms for the configured location
  4. Fetches or generates Zoom activation codes for each room
  5. Displays a combined table with both codes
  6. Saves activation_codes.csv for printing or reference
  7. Provides an interactive search prompt to look up individual rooms

What the Vendor Receives

A zip file downloaded from the project's GitHub release link. It contains:

  • ISI-AV-Activation.exe — the activation code tool (self-updating)
  • VENDOR GUIDE.md — step-by-step instructions for the vendor

Self-updating: The vendor only downloads the zip once. On every subsequent launch, the exe checks for a newer version and updates itself automatically.

Prerequisites

Before the tool will work for a building:

  • Rooms must already exist in both Neat Pulse and Zoom Rooms
  • Room names should match between the two platforms
  • The tool retrieves codes for existing rooms — it does not create rooms

Duplicate room names: If two rooms within the same platform share a name, the tool will flag them. Ask the AV architect to rename them before distributing the tool.

How the Vendor Uses It

  1. Double-click ISI-AV-Activation.exe
  2. Wait about 30 seconds while rooms load
  3. A table appears with all rooms and their codes
  4. Type part of a room name to search, or press Enter to exit
  5. A CSV file is saved automatically for printing

The session auto-closes after 55 minutes to prevent token expiry.
